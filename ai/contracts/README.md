# 📜 AI SHARED CONTRACTS DIRECTORY

Thư mục này lưu trữ các file định nghĩa giao tiếp kỹ thuật giữa Codex và Antigravity:
- `asset_manifest.json`: Do Antigravity lập, định nghĩa danh sách ảnh, kích thước, FPS, trạng thái.
- `state_events.json`: Do Codex lập, định nghĩa các sự kiện bàn phím/chuột/timer phát ra từ hệ thống.
- `ui_protocol.json`: Giao thức dữ liệu truyền giữa giao diện người dùng và backend.

Khi hai bên làm việc qua các file hợp đồng này, mã nguồn sẽ hoàn toàn khớp nhau mà không cần tranh luận qua lại.
